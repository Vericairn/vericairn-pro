# Security

## Reporting a vulnerability

Report a security problem privately, never in a public issue or pull request. Use GitHub's private vulnerability
reporting: on this repository's **Security** tab, choose **Report a vulnerability**. If you cannot use it, email
vericairn@jasonfurr.com.

Say what you found, the commit it affects, and how to reproduce it. The maintainer reads every report. Vericairn has
no support commitment yet, so no response time is promised.

## What this covers

The code in this repository. Nothing has been released from it yet. Problems in the Community edition belong in
[Vericairn](https://github.com/Vericairn/vericairn/security).
