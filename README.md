# Vericairn Pro

Vericairn Pro holds the coordination programs that operate goals across work orders: planning a goal into work,
choosing the next eligible work and scheduling it across machines and agents, with Pro's Workbench workspace and
command-line additions. It builds on the Community edition, [Vericairn](https://github.com/Vericairn/vericairn),
which is Apache-2.0 and complete without Pro.

Nothing here is released yet. The first coordination program is planned as work order GOAL-05 of the Vericairn
estate.
